1- install fastAPI and server 

>> pip install fastapi uvicorn

verify : 

>> pip show fastapi

2- main file 

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello FastAPI!"}


3- Run fastapi 


>> python -m uvicorn main:app 

FO: Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)

4- Access Swagger 

>> http://127.0.0.1:8000/docs


5- install fastapi 

>> py -3.12 -m pip install fastapi uvicorn

- uvicorn is the ASGI server in the fast api 

6- check all the package 

>> py -3.12 -m pip list
